# Design System — Juan2.0 Portfolio

**No cambiar sin aprobación explícita del usuario.**

## Paleta

Monocromática estricta. Sin colores de acento.

| Token | Valor | Uso |
|-------|-------|-----|
| background | #FFFFFF | Fondo |
| foreground | #4D4D4D | Texto, títulos (pedido explícito de Juan, 21 abr 2026) |
| muted | #B0B0B0 | Texto secundario, menú inactivo |
| border | #E5E5E5 | Divisores (con moderación) |

## Tipografía

**Jost** (variable) como primaria, Inter como fallback. Única font family.

## Animaciones

Solo opacity y transform. Tween, no spring. Máximo scale: 1.02. Duraciones: 300-500ms.

## Regla

Si una decisión visual no ayuda a que el trabajo de Juan Pablo se vea mejor, no se agrega.

Implementar la feature usando Test-Driven Development estricto.

Reglas:
1. Escribí UN SOLO test que falle (Red)
2. Corré el test — confirmá que falla por la razón correcta
3. Escribí el MÍNIMO código para que pase (Green)
4. Corré el test — confirmá que pasa
5. Repetí desde el paso 1 para el siguiente comportamiento
6. Solo refactorizá DESPUÉS de que todos los tests pasen

IMPORTANTE:
- NO escribas múltiples tests de golpe
- NO modifiques un test para forzar que pase
- Cada ciclo debe ser un commit lógico separado (si el usuario lo autoriza)
- Usá describe/it con nombres descriptivos en español

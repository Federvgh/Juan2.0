Crear una nueva página de proyecto para el portfolio.

Instrucciones:
1. Pedí el nombre del proyecto, descripción corta, y categoría (automotriz, producto, conceptual)
2. Creá la ruta en app/(portfolio)/projects/[slug]/ siguiendo el patrón de los proyectos existentes
3. Usá next/image con sizes y priority para la imagen hero
4. Incluí navegación anterior/siguiente entre proyectos
5. Asegurate de que las imágenes tengan alt descriptivo para SEO
6. Agregá el proyecto al array/CMS de proyectos

Usá TDD: escribí un test que verifique que la página renderiza con los datos del proyecto antes de implementar.

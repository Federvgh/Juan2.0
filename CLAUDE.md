# Juan2.0 - Portfolio de Juan Pablo Tazzioli

Portfolio para un diseñador industrial argentino (UNC Córdoba).
Proyectos actuales: diseño automotriz, calzado conceptual, semáforo modular, medalla deportiva.

## Contexto clave

- El sitio actual es HTML/CSS/JS puro con Bootstrap 4 — se va a reconstruir con Next.js
- El cliente NO es developer; el contenido debe ser fácil de actualizar
- Audiencia: estudios de diseño internacionales y potenciales empleadores (bilingüe ES/EN)
- Las imágenes de proyectos son renders 3D pesados — optimización de imágenes es crítica
